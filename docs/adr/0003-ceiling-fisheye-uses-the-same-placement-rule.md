# A ceiling fisheye uses the same placement rule

Fisheye cameras at our sites are mounted on the ceiling looking straight down. We judge them with the same scene-profile rule as every other camera: the counting line sits at the recommended distance from the point below the camera, and its feet angle decides the verdict. Only the lens model changes (fixed 90 degree tilt, equidistant projection for framing, coverage and pixel density).

## Considered Options

- **Coverage and pixel density instead of the feet angle**: the usual overhead-counting rule, but it would need new thresholds per scene and would judge fisheye placements differently from the rest.
- **Show only, no verdict**: avoids a wrong judgement but leaves the installer without an answer.
