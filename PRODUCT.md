# Product

## Register

product

## Users

Technical operators, field engineers, and camera deployment planners use this tool while deciding where to mount a camera relative to a person or target zone. They need fast geometry feedback, clear pass/fail judgment, and a lookup table they can reference or hand to implementation teams.

## Product Purpose

Camera Placement Lookup turns height and distance rules into a practical placement console. Success means a user can see whether a placement is best, acceptable, or out of range, understand which rule is driving the result, and apply a recommended distance without reading dense rule prose.

## Brand Personality

Precise, calm, instrument-like. The interface should feel like a trusted technical console, not a marketing page or decorative demo.

## Anti-references

Avoid generic SaaS dashboards, decorative card grids, low-contrast gray text, duplicated slider plus number controls, buried verdicts, and prose-heavy rule explanations where a visual range or status chip would answer faster.

## Design Principles

- Lead with the verdict: the first answer is whether the current placement works.
- Keep feet priority explicit: counting geometry matters before face profile quality.
- Make numeric work editable and legible: measurements use monospace, stable formatting, and direct inputs.
- Show the rule visually: diagrams and range bars should replace dense paragraphs where possible.
- Preserve the lookup table as the engineering source of truth.

## Accessibility & Inclusion

Target WCAG AA contrast, keyboard-operable controls, clear focus states, no color-only status, 44px touch targets on narrow screens, form input sizes that avoid mobile browser zoom, and reduced-motion-safe transitions.
